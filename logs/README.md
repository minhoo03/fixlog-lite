# Logs

회의, 대화 요약, 작업 기록 등 당시 맥락을 보존해야 하는 자료를 `YYYY/MM/YYYY-MM-DD--slug.md` 형식으로 저장한다.

기존 로그는 오탈자나 민감정보 제거처럼 명시적으로 요청된 경우 외에는 수정하지 않는다. 후속 내용은 새 로그로 남기고 관련 문서를 연결한다.
